# BFS and DFS

A C++ implementation of breadth-first search and depth-first search on an undirected graph.

## Complexity

- Time: `O(V + E)`
- Space: `O(V)`

## Compile

```bash
g++ bfs_dfs.cpp -o bfs_dfs
```

## Run

```bash
./bfs_dfs
```

Enter the number of vertices and edges, followed by the undirected edges and a starting vertex.

```text
5 5
0 1
0 2
1 3
2 4
3 4
0
```
